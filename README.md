# March 2026 Sales Analysis

An Excel-based sales analysis case study prepared as part of a Data Science training project.

## Project contents

- `data/raw/sales_march_2026_raw.xlsx` — source sales workbook.
- `deliverables/sales_analysis_workbook.xlsx` — completed analysis workbook.
- `deliverables/sales_analysis_summary.pdf` — results summary.
- `deliverables/sales_analysis_report.pdf` and `reports/sales_analysis_report.docx` — final report in PDF and editable formats.
- `deliverables/sales_analysis_presentation.pptx` — presentation of the findings.
- `deliverables/` — supporting charts and project-organization document.

## Analysis scope

The project organizes the March 2026 sales data, calculates sales totals and business indicators in Excel, and communicates the results through tables, charts, a written report, and a presentation.

## Notes

This repository preserves the completed deliverables from one selected version of the project. Backup copies and duplicate ZIP archives were intentionally left out. The analysis is Excel-based; no Python training pipeline is included.
